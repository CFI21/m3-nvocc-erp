# M3 Equipment / Container Master SOP

The following SOPs apply inside the existing M3 NVOCC ERP.

## EQ-SOP-01 Container Acquisition & Coding
1. Start from an approved acquisition/source transaction.
2. Register the actual physical container number once.
3. Assign economic owner/provider: Principal, Overseas Partner, Leasing Company, Investor, Agent Supplied or SOC.
4. Assign Principal (where applicable) and operational branch/agent/depot custody.
5. Complete technical, CSC and inspection verification.
6. Store picture/attachment references.
7. Make the unit AVAILABLE only when required controls pass.

## EQ-SOP-02 Booking Equipment Allocation
1. Read the authoritative Booking/Job equipment requirement.
2. Check eligible local Container Master stock.
3. Protect safety stock.
4. Reserve actual container numbers.
5. Create shortage work only for residual demand.
6. Release/B-L must use those same allocated physical records.

## EQ-SOP-03 Shortage Resolution
Expected return/repair -> nearby reposition -> partner/agent supply -> lease -> SOC -> purchase review for structural shortage.

## EQ-SOP-04 Custody Transfer
Record source custody -> approval where required -> depart/in transit -> destination receipt -> transfer branch/agent/depot custody -> audit.

## EQ-SOP-05 Lease
Approved request -> lessor/contract -> actual boxes -> on-hire -> available -> cost accrual -> idle/off-hire watch -> off-hire after obligations clear.

## EQ-SOP-06 Purchase
Approved request/PO -> supplier -> actual boxes -> purchase refs -> inspection -> Principal ownership -> custody -> available.

## EQ-SOP-07 Financial Control
Post revenue/cost -> source reference -> commission/share rule -> four-eyes where required -> reconcile accrual/actual -> container P&L.

## EQ-SOP-08 Empty Return
Gate-out full -> detention/free-day control -> empty return -> condition check -> outstanding cost closure -> available at return depot.

## EQ-SOP-09 Sale / Disposal
Allocate-for-sale -> block new allocation -> approve sale -> invoice/proceeds -> physical release/disposal -> remove from active-fleet KPI.

## EQ-SOP-10 Exception / Override
System block -> reason -> authorized checker/finance/management approval -> immutable audit -> controlled execution -> KPI/control-tower review.
